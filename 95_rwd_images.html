RWD Images

Responsive images means an image never overflows its container as the viewport shrinks, and ideally scales to make good use of the space it's given. Fixed-pixel-width images are one of the most common causes of unwanted horizontal scrolling on phones, so this is one of the core techniques underpinning all of RWD.

Using the width Property

Setting width: 100% (with height: auto to preserve the aspect ratio) makes an image's width always match its container — including scaling it up past its own native resolution if the container is larger, which can blur the image.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         img {
             width: 100%;
             height: auto;
         }
     </style>
</head>
<body>

     <img src="img_forest.jpg" alt="Forest">

</body>
</html>

Native image is 600×400 — here it's forced into a 250px-wide container, so it scales down:

Same image, forced into a wider 500px container — width: 100% scales it up past its native 600px width, and it starts to look soft:

Using the max-width Property

If scaling up past the native resolution isn't wanted, max-width: 100% is the safer default: the image still shrinks down to fit a narrower container, but is never stretched larger than its own original size.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         img {
             max-width: 100%;
             height: auto;
         }
     </style>
</head>
<body>

     <img src="img_forest.jpg" alt="Forest">

</body>
</html>

250px container — still shrinks down, same as width: 100%:

500px container — unlike the previous example, max-width: 100% stops growing once the image hits its native 600px width, instead of stretching past it:

Note: max-width: 100% is generally the better default of the two: it gets the same shrink-to-fit behavior on small screens without the blurring risk of scaling an image beyond its native resolution on a large one.

Background Images and background-size

For CSS background images (rather than <img> elements), the background-size property controls how the image fills its box. Three common values behave very differently when the box's aspect ratio doesn't match the image's:

  • contain — scales the image as large as possible while keeping its aspect ratio and staying fully inside the box; this can leave empty space on two sides.
  • 100% 100% — stretches the image to exactly fill the box on both axes, ignoring its original aspect ratio, which can visibly distort it.
  • cover — scales the image to completely fill the box while keeping its aspect ratio, cropping whatever overflows.
Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .bg-contain {
             background-image: url("background.jpg");
             background-repeat: no-repeat;
             background-size: contain;
         }
         .bg-stretch { background-size: 100% 100%; }
         .bg-cover { background-size: cover; }
     </style>
</head>
<body>

     <div class="bg-contain"></div>
     <div class="bg-stretch"></div>
     <div class="bg-cover"></div>

</body>
</html>

background-size: contain — whole image visible, bars on the sides:

background-size: 100% 100% — stretched, aspect ratio distorted:

background-size: cover — fills the box, edges cropped:

Different Images for Different Devices

A large, detailed background image makes sense on a desktop screen, but is often wasted bandwidth and detail on a small phone screen. A media query can swap the background-image entirely, rather than just resizing the same file, serving a smaller or differently-cropped image below a chosen breakpoint:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         body {
             background-image: url("pineapple.jpg");
             background-size: cover;
         }

         @media only screen and (min-width: 400px) {
             body {
                 background-image: url("img_mountains.jpg");
             }
         }
     </style>
</head>
<body></body>
</html>

Below 400px — a smaller, square-cropped image loads:

400px and wider — a different, wide landscape image loads instead:

Note: This example uses real images already in this site's images/ folder (pineapple.jpg, img_mountains.jpg) in place of W3Schools' own device-specific sample files, since those aren't bundled with this project; the mechanism — swapping background-image at a breakpoint — is identical.

The HTML picture Element

The <picture> element lets the browser pick which image source to actually download, based on each <source>'s media condition — unlike a CSS background-image swap, this can save bandwidth on phones by never even requesting the desktop-sized file. A fallback <img> is required for browsers that don't support <picture>.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
</head>
<body>

     <picture>
         <source srcset="img_mountains.jpg" media="(min-width: 650px)">
         <source srcset="img_forest.jpg" media="(min-width: 465px)">
         <img src="pineapple.jpg" alt="Fallback image" style="width: auto;">
     </picture>

</body>
</html>

This container is 650px or wider here, so the browser picked the first matching source, img_mountains.jpg:

Note: <source> conditions are checked in order, and the browser uses the first one that matches its viewport; if none match, it falls back to the <img>. This differs from the srcset attribute on a plain <img> (not shown here), which lets the browser choose based on pixel density too, not just viewport width.

Responsive Image Gallery

Combining flexible images with a flex container builds a gallery that reflows its column count as the viewport narrows — here, three images per row on wide screens collapse to one per row on narrow ones:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .gallery {
             display: flex;
             flex-wrap: wrap;
             gap: 10px;
         }
         .gallery figure {
             margin: 0;
             flex: 1 1 30%;
         }
         .gallery img { width: 100%; height: auto; }

         @media only screen and (max-width: 500px) {
             .gallery figure { flex: 1 1 100%; }
         }
     </style>
</head>
<body>

     <div class="gallery">
         <figure><img src="img_5terre.jpg" alt="Cinque Terre"></figure>
         <figure><img src="img_forest.jpg" alt="Forest"></figure>
         <figure><img src="img_mountains.jpg" alt="Mountains"></figure>
     </div>

</body>
</html>

Wide — three per row:

Below 500px — stacked one per row:
