CSS Multi-column Layout

The multi-column layout module lets text flow across two or more columns, like a newspaper, instead of staying in one wide block. The browser automatically re-flows the content as the viewport or column settings change, which is far simpler than manually splitting text into separate elements.

CSS Column Span and Column Width

The column-span property specifies how many columns an element should span across. Setting it to all on a heading inside a multi-column container makes that heading break out and stretch across every column, which is a common way to add a full-width title above column text.

The column-width property specifies a suggested, optimal column width — rather than fixing an exact number of columns, the browser works out how many columns of roughly that width will fit, and creates that many (so the actual column count can change as the window resizes).

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .newspaper {
             column-count: 3;
             column-gap: 40px;
             column-rule: 3px outset #777;
         }
         h2 {
             column-span: all;
         }
     </style>
</head>
<body>

CSS Multi-column Properties

Property Description
column-countSpecifies the number of columns an element should be divided into
column-fillSpecifies how to fill columns, balanced or not
column-gapSpecifies the gap between the columns
column-ruleShorthand for setting all the column-rule-* properties
column-rule-colorSpecifies the color of the rule between columns
column-rule-styleSpecifies the style of the rule between columns
column-rule-widthSpecifies the width of the rule between columns
column-spanSpecifies how many columns an element should span across
column-widthSpecifies a suggested, optimal width for the columns
columnsShorthand for setting column-width and column-count
