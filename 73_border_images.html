CSS Border Images

The border-image property lets an image be used as an element's border instead of a plain solid/dashed/dotted line. The source image is sliced into nine regions — like a tic-tac-toe grid — the four corner pieces are placed at the element's corners untouched, and the four edge pieces in between are stretched or repeated to fill the rest of the border on each side.

border-image is shorthand for five longhand properties:

Property Description
border-image-sourceThe path to the image used as the border
border-image-sliceHow the source image is sliced into its nine regions
border-image-widthThe width of the border image
border-image-outsetHow far the border image extends beyond the border box
border-image-repeatWhether the edge regions are repeated, rounded, or stretched

This lesson's examples all slice and tile the same source image:

Note: For border-image to have any visible effect, the element must also have an ordinary border property set (its width reserves the space the image will occupy) — typically border: Npx solid transparent;, so the image shows through cleanly with no solid-color border underneath it.

Border Image - Round

With the round keyword, the slice value 30 cuts 30 pixels in from each edge of the source image for the corner and edge regions; the middle edge pieces are then tiled along each side, and the browser rescales the tile so a whole number of copies fit exactly, instead of cutting one off halfway.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #borderimg {
             border: 10px solid transparent;
             padding: 15px;
             border-image: url(border.png) 30 round;
         }
     </style>
</head>
<body>

     <h1>The border-image Property</h1>
     <p>Here, the border image is repeated (rounded) to fill the area:</p>

     <p id="borderimg">border-image: url(border.png) 30 round;</p>

</body>
</html>

border-image: url(border.png) 30 round;

Border Image - Stretch

Swapping the repeat keyword to stretch instead tiles nothing: each edge region of the sliced image is stretched to fill the whole length of its side, however long that side is.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #borderimg {
             border: 10px solid transparent;
             padding: 15px;
             border-image: url(border.png) 30 stretch;
         }
     </style>
</head>
<body>

     <h1>The border-image Property</h1>
     <p>Here, the border image is stretched to fill the area:</p>

     <p id="borderimg">border-image: url(border.png) 30 stretch;</p>

</body>
</html>

border-image: url(border.png) 30 stretch;

Note: Compare this to the round example above using the exact same source image and slice value — the repeat keyword alone completely changes the texture of the result, tiled diamonds versus a smooth stretched gradient of color.

Border Image - Slice Values

Different border-image-slice values dramatically change how the same source image looks once applied, because the slice value controls exactly how much of the image counts as "corner" versus "edge" before any rounding or stretching happens. Slice values can be given in pixels or as a percentage of the source image's own size.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #borderimg1 {
             border: 10px solid transparent;
             padding: 15px;
             border-image: url(border.png) 50 round;
             margin-bottom: 15px;
         }

         #borderimg2 {
             border: 10px solid transparent;
             padding: 15px;
             border-image: url(border.png) 20% round;
             margin-bottom: 15px;
         }

         #borderimg3 {
             border: 10px solid transparent;
             padding: 15px;
             border-image: url(border.png) 30% round;
             margin-bottom: 15px;
         }
     </style>
</head>
<body>

     <h1>The border-image Property</h1>
     <p>Different slice values completely changes the look of the border image:</p>

     <div id="borderimg1">border-image: url(border.png) 50 round;</div>
     <div id="borderimg2">border-image: url(border.png) 20% round;</div>
     <div id="borderimg3">border-image: url(border.png) 30% round;</div>

</body>
</html>
border-image: url(border.png) 50 round;
border-image: url(border.png) 20% round;
border-image: url(border.png) 30% round;

Note: All three boxes above share the exact same source image, border width, and round repeat — only the slice number changes. A larger slice value (like 50) grabs more of the image for each corner, pulling more of the design inward, while a percentage-based slice (like 20% or 30%) scales proportionally to the source image's own dimensions rather than a fixed pixel count.
