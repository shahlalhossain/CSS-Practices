CSS Flex Container

Once an element's display is set to flex (or inline-flex), it becomes a flex container, and seven properties on that container control how its flex items behave: display, flex-direction, flex-wrap, flex-flow, justify-content, align-items, and align-content. This lesson walks through each one with every value it supports.

The flex-direction Property

flex-direction sets the axis flex items are laid out along. It accepts four values: row (default), row-reverse, column, and column-reverse.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: flex;
             flex-direction: row;
         }
     </style>
</head>
<body>

     <h1>flex-direction: row</h1>
     <p>flex-direction: row; displays the flex items horizontally (from left to right):</p>

     <div class="container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
     </div>

</body>
</html>

The flex-wrap Property

flex-wrap specifies whether flex items are forced onto a single line or allowed to wrap onto multiple lines when there isn't enough room. It accepts nowrap (default), wrap, and wrap-reverse. Each example below uses nine items in a fixed-width container so the behavior is visible without needing to resize the browser.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: flex;
             flex-wrap: nowrap;
         }
     </style>
</head>
<body>

     <h1>flex-wrap: nowrap</h1>
     <p>flex-wrap: nowrap; specifies that the flex items will not wrap (this is default):</p>

     <div class="container">
         <div>1</div><div>2</div><div>3</div>
         <div>4</div><div>5</div><div>6</div>
         <div>7</div><div>8</div><div>9</div>
     </div>

     <p>Try resizing the browser window!</p>

</body>
</html>

The align-content Property

align-content aligns the flex lines themselves (not individual items) along the cross axis, and only has a visible effect when flex-wrap causes items to wrap onto more than one line. Its values are stretch (default), center, flex-start, flex-end, space-between, space-around, and space-evenly. Each example below wraps nine items inside a tall container.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: flex;
             height: 400px;
             flex-wrap: wrap;
             align-content: center;
     }
     </style>
</head>
<body>

     <h1>align-content: center</h1>
     <p>align-content: center; - The flex lines are packed toward the center of the container:</p>

     <div class="container">
         <div>1</div><div>2</div><div>3</div>
         <div>4</div><div>5</div><div>6</div>
         <div>7</div><div>8</div><div>9</div>
     </div>

</body>

True Centering With Flexbox

A common layout problem — centering an element both horizontally and vertically — becomes trivial with flexbox. Setting both justify-content: center; and align-items: center; on the container perfectly centers its item(s) in both directions at once:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: flex;
             justify-content: center;
             align-items: center;
             height: 300px;
     }
     </style>
</head>
<body>

     <h1>True Centering</h1>
     <p>A flex container with both the justify-content and the align-items properties set to center will align the flex item(s) in the center (in both axis).</p>

     <div class="container">
         <div>1</div>
     </div>

</body>
</html>
