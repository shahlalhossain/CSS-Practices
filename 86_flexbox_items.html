CSS Flex Items

The previous lesson covered properties that go on the flex container. This lesson covers the properties that go on the flex items themselves (the direct children of a flex container): order, flex-grow, flex-shrink, flex-basis, the flex shorthand, and align-self.

The order Property

The order property controls the order flex items appear in, regardless of their order in the HTML source. Its default value is 0; items are laid out from the lowest order value to the highest, and items sharing the same value fall back to source order among themselves.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .flex-container {
             display: flex;
         }
         .flex-container div:nth-child(1) { order: 3; }
         .flex-container div:nth-child(2) { order: 2; }
         .flex-container div:nth-child(3) { order: 4; }
         .flex-container div:nth-child(4) { order: 1; }
     </style>
</head>
<body>

     <h1>The order Property</h1>
     <p>Item "1" has order: 3, item "2" has order: 2, item "3" has order: 4, and item "4" has order: 1. They render in ascending order value, not source order:</p>

     <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
     </div>

</body>
</html>

Item "1" has order: 3, item "2" has order: 2, item "3" has order: 4, item "4" has order: 1 — they render by ascending order value:

The flex-grow Property

The flex-grow property lets an item grow to consume any leftover space in the container, relative to its siblings. Its default value is 0 (don't grow). A value is a unitless proportion: if every item has flex-grow: 1, the remaining space is split evenly; an item with a higher value takes a proportionally larger share of what's left over.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .flex-container {
             display: flex;
         }
         .flex-container div:nth-child(1) { flex-grow: 1; }
         .flex-container div:nth-child(2) { flex-grow: 1; }
         .flex-container div:nth-child(3) { flex-grow: 4; }
     </style>
</head>
<body>

     <h1>The flex-grow Property</h1>
     <p>Item "3" has flex-grow: 4, so it grows four times as much as items "1" and "2" (both flex-grow: 1) when the container has leftover space:</p>

     <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
     </div>

</body>
</html>

Item "3" has flex-grow: 4, so it grows four times as much as items "1" and "2" (both flex-grow: 1):

1
2
3

The flex-shrink Property

The flex-shrink property is the opposite of flex-grow: it lets an item shrink relative to its siblings when the container is too small to fit everything at its natural width. Its default value is 1 (items may shrink evenly); setting it to 0 stops an item from shrinking at all, and a higher value shrinks an item proportionally more than its siblings.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .flex-container {
             display: flex;
             width: 400px;
         }
         .flex-container div { width: 100px; }
         .flex-container div:nth-child(3) { flex-shrink: 8; }
     </style>
</head>
<body>

     <h1>The flex-shrink Property</h1>
     <p>The container is too narrow to fit six 100px items at full width. Item "3" has flex-shrink: 8, so it shrinks much more aggressively than its siblings (default flex-shrink: 1):</p>

     <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
         <div>5</div>
         <div>6</div>
     </div>

</body>
</html>

The container is too narrow to fit six 100px items. Item "3" has flex-shrink: 8, so it shrinks far more than its siblings:

The flex-basis Property

The flex-basis property sets an item's initial length before any growing or shrinking is applied, in the same units as width — it's the starting point the flex-grow/flex-shrink calculations work from. Its default value is auto, which falls back to the item's own width (or content size, if none is set).

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .flex-container {
             display: flex;
         }
         .flex-container div:nth-child(3) { flex-basis: 250px; }
     </style>
</head>
<body>

     <h1>The flex-basis Property</h1>
     <p>Item "3" starts out at 250px wide (its flex-basis) before any growing or shrinking happens, regardless of the width set on the other items:</p>

     <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
     </div>

</body>
</html>

Item "3" has flex-basis: 250px — it starts out wider than the other items before any growing/shrinking:

3

The flex Property (Shorthand)

The flex property is a shorthand for flex-grow, flex-shrink, and flex-basis combined, in that order. It's recommended to use this shorthand rather than setting the three properties individually, since it also resets any value you leave out to its proper default instead of inheriting a stale one.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .flex-container {
             display: flex;
         }
         .flex-container div:nth-child(3) { flex: 1 0 150px; }
     </style>
</head>
<body>

     <h1>The flex Property</h1>
     <p>Item "3" has flex: 1 0 150px — a flex-grow of 1, a flex-shrink of 0 (it won't shrink below its basis), and a flex-basis of 150px:</p>

     <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
     </div>

</body>
</html>

Item "3" has flex: 1 0 150px — grow: 1, shrink: 0, basis: 150px:

1
2
3
4

Note: The default value for the flex shorthand is 0 1 auto.

The align-self Property

The align-self property overrides the container's align-items value for one individual flex item, letting a single item be aligned differently from its siblings along the cross axis. It accepts the same values as align-items: auto (default — defers to the container), stretch, center, flex-start, flex-end, and baseline. The examples below use a 200px-tall container so the vertical alignment is visible.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .flex-container {
             display: flex;
             height: 200px;
         }
         .flex-container div:nth-child(3) { align-self: center; }
     </style>
</head>
<body>

     <h1>align-self: center</h1>
     <p>Item "3" has align-self: center, so it's centered vertically while its siblings stay stretched to the container's default alignment:</p>

     <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
     </div>

</body>
</html>

Item "3" has align-self: center — it's centered vertically while its siblings stay stretched to fill the container:

1
2
3
4
Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .flex-container {
             display: flex;
             height: 200px;
         }
         .flex-container div:nth-child(2) { align-self: flex-start; }
         .flex-container div:nth-child(3) { align-self: flex-end; }
     </style>
</head>
<body>

     <h1>align-self: flex-start / flex-end</h1>
     <p>Item "2" has align-self: flex-start (pinned to the top) and item "3" has align-self: flex-end (pinned to the bottom), while items "1" and "4" keep the container's default alignment:</p>

     <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
     </div>

</body>
</html>

Item "2" has align-self: flex-start (pinned to top), item "3" has align-self: flex-end (pinned to bottom):

1
2
3
4

Note: align-self only has a visible effect when the container has extra cross-axis space to distribute — here, a fixed height on the container. It has no effect if flex-wrap: wrap; is set and there's more than one flex line, since align-content takes over aligning whole lines in that case.

CSS Flex Item Properties

Property Description
orderSets the order of a flex item relative to its siblings
flex-growSets how much a flex item will grow relative to the rest
flex-shrinkSets how much a flex item will shrink relative to the rest
flex-basisSets the initial length of a flex item
flexShorthand for flex-grow, flex-shrink, and flex-basis
align-selfOverrides align-items for one flex item
