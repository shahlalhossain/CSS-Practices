CSS Colors

Lesson #6 (CSS Colors) already covered the basics: predefined color names, and using colors for background/text/border. This lesson goes deeper into the numeric color notations CSS supports — RGB/RGBA, HEX/HEXA, and HSL/HSLA — which W3Schools splits across its own dedicated sub-pages (css_colors_rgb.asp, css_colors_hex.asp, css_colors_hsl.asp).

CSS RGB and RGBA Colors

An RGB color value represents RED, GREEN, and BLUE light sources, written as rgb(red, green, blue), where each parameter is an integer between 0 and 255. Equal values for all three channels always produce a shade of gray.

Example Code Sample Output
<!DOCTYPE html>
<html>
<body>

     <h3 style="background-color:rgb(255, 0, 0);">rgb(255, 0, 0)</h3>
     <h3 style="background-color:rgb(0, 0, 255);">rgb(0, 0, 255)</h3>
     <h3 style="background-color:rgb(60, 179, 113);">rgb(60, 179, 113)</h3>
     <h3 style="background-color:rgb(238, 130, 238);">rgb(238, 130, 238)</h3>
     <h3 style="background-color:rgb(255, 165, 0);">rgb(255, 165, 0)</h3>
     <h3 style="background-color:rgb(106, 90, 205);">rgb(106, 90, 205)</h3>

</body>
</html>

rgb(255, 0, 0)

rgb(0, 0, 255)

rgb(60, 179, 113)

rgb(238, 130, 238)

rgb(255, 165, 0)

rgb(106, 90, 205)

RGBA color values are an extension of RGB with an added alpha channel, written rgba(red, green, blue, alpha), where alpha is a number between 0.0 (fully transparent) and 1.0 (fully opaque).

Example Code Sample Output
<!DOCTYPE html>
<html>
<body style="background-color: #f1f1f1;">

     <h3 style="background-color:rgba(255, 99, 71, 0);">rgba(255, 99, 71, 0)</h3>
     <h3 style="background-color:rgba(255, 99, 71, 0.2);">rgba(255, 99, 71, 0.2)</h3>
     <h3 style="background-color:rgba(255, 99, 71, 0.4);">rgba(255, 99, 71, 0.4)</h3>
     <h3 style="background-color:rgba(255, 99, 71, 0.6);">rgba(255, 99, 71, 0.6)</h3>
     <h3 style="background-color:rgba(255, 99, 71, 0.8);">rgba(255, 99, 71, 0.8)</h3>
     <h3 style="background-color:rgba(255, 99, 71, 1);">rgba(255, 99, 71, 1)</h3>

</body>
</html>

rgba(255, 99, 71, 0)

rgba(255, 99, 71, 0.2)

rgba(255, 99, 71, 0.4)

rgba(255, 99, 71, 0.6)

rgba(255, 99, 71, 0.8)

rgba(255, 99, 71, 1)

Note: Alpha is not the same thing as the opacity property: opacity fades the entire element (including any text and children), while an alpha channel on the color value only fades that one color, leaving everything else on the element at full strength.

CSS HEX and HEXA Colors

A hexadecimal color value is written #RRGGBB, where RR (red), GG (green), and BB (blue) are hexadecimal integers from 00 to ff (the same 0–255 range as RGB, just in base 16).

Example Code Sample Output
<!DOCTYPE html>
<html>
<body>

     <h3 style="background-color:#ff0000;">#ff0000</h3>
     <h3 style="background-color:#0000ff;">#0000ff</h3>
     <h3 style="background-color:#3cb371;">#3cb371</h3>
     <h3 style="background-color:#ee82ee;">#ee82ee</h3>
     <h3 style="background-color:#ffa500;">#ffa500</h3>
     <h3 style="background-color:#6a5acd;">#6a5acd</h3>

</body>
</html>

#ff0000

#0000ff

#3cb371

#ee82ee

#ffa500

#6a5acd

A 3-digit hex code (#rgb) is shorthand for a 6-digit code, but only works when each pair of digits is identical — each digit is simply doubled. #fc9 is shorthand for #ffcc99, #f0f for #ff00ff, and #b58 for #bb5588.

HEXA adds a fourth pair of digits for the alpha channel: #RRGGBBAA. The examples below reuse the same six colors as above with 80 (about 50%) alpha appended.

Example Code Sample Output
<!DOCTYPE html>
<html>
<body style="background-color: #f1f1f1;">

     <h3 style="background-color:#ff000080;">#ff000080</h3>
     <h3 style="background-color:#0000ff80;">#0000ff80</h3>
     <h3 style="background-color:#3cb37180;">#3cb37180</h3>
     <h3 style="background-color:#ee82ee80;">#ee82ee80</h3>

</body>
</html>

#ff000080

#0000ff80

#3cb37180

#ee82ee80

CSS HSL and HSLA Colors

HSL stands for Hue, Saturation, and Lightness, written hsl(hue, saturation%, lightness%):

  • Hue is a degree on the color wheel from 0 to 360 (0 = red, 120 = green, 240 = blue)
  • Saturation is a percentage, where 0% is a shade of gray and 100% is the full color
  • Lightness is also a percentage, where 0% is black and 100% is white
Example Code Sample Output
<!DOCTYPE html>
<html>
<body>

     <h3 style="background-color:hsl(0, 100%, 50%);">hsl(0, 100%, 50%)</h3>
     <h3 style="background-color:hsl(240, 100%, 50%);">hsl(240, 100%, 50%)</h3>
     <h3 style="background-color:hsl(147, 50%, 47%);">hsl(147, 50%, 47%)</h3>
     <h3 style="background-color:hsl(300, 76%, 72%);">hsl(300, 76%, 72%)</h3>
     <h3 style="background-color:hsl(39, 100%, 50%);">hsl(39, 100%, 50%)</h3>
     <h3 style="background-color:hsl(248, 53%, 58%);">hsl(248, 53%, 58%)</h3>

</body>
</html>

hsl(0, 100%, 50%)

hsl(240, 100%, 50%)

hsl(147, 50%, 47%)

hsl(300, 76%, 72%)

hsl(39, 100%, 50%)

hsl(248, 53%, 58%)

Keeping hue fixed at 0 and lightness fixed at 50% while lowering saturation in steps shows saturation fading a pure color toward gray:

Example Code Sample Output
<!DOCTYPE html>
<html>
<body>

     <h3 style="background-color:hsl(0, 100%, 50%);">hsl(0, 100%, 50%)</h3>
     <h3 style="background-color:hsl(0, 80%, 50%);">hsl(0, 80%, 50%)</h3>
     <h3 style="background-color:hsl(0, 60%, 50%);">hsl(0, 60%, 50%)</h3>
     <h3 style="background-color:hsl(0, 40%, 50%);">hsl(0, 40%, 50%)</h3>
     <h3 style="background-color:hsl(0, 20%, 50%);">hsl(0, 20%, 50%)</h3>
     <h3 style="background-color:hsl(0, 0%, 50%);">hsl(0, 0%, 50%)</h3>

</body>
</html>

hsl(0, 100%, 50%)

hsl(0, 80%, 50%)

hsl(0, 60%, 50%)

hsl(0, 40%, 50%)

hsl(0, 20%, 50%)

hsl(0, 0%, 50%)

Keeping hue and saturation fixed (0, 100%) while raising lightness in steps moves from black, through full red, to white:

<!DOCTYPE html>

<body>

     <h3 style="background-color:hsl(0, 100%, 50%);">hsl(0, 100%, 50%)</h3>
     <h3 style="background-color:hsl(0, 100%, 75%);">hsl(0, 100%, 75%)</h3>
     <h3 style="background-color:hsl(0, 100%, 90%);">hsl(0, 100%, 90%)</h3>
     <h3 style="background-color:hsl(0, 100%, 100%);">hsl(0, 100%, 100%)</h3>

</body>
</html>

HSLA works the same way as RGBA: it adds an alpha parameter for transparency, written hsla(hue, saturation%, lightness%, alpha).

Example Code Sample Output
<!DOCTYPE html>
<html>
<body style="background-color: #f1f1f1;">

     <h3 style="background-color:hsla(9, 100%, 64%, 0);">hsla(9, 100%, 64%, 0)</h3>
     <h3 style="background-color:hsla(9, 100%, 64%, 0.2);">hsla(9, 100%, 64%, 0.2)</h3>
     <h3 style="background-color:hsla(9, 100%, 64%, 0.4);">hsla(9, 100%, 64%, 0.4)</h3>
     <h3 style="background-color:hsla(9, 100%, 64%, 0.6);">hsla(9, 100%, 64%, 0.6)</h3>
     <h3 style="background-color:hsla(9, 100%, 64%, 0.8);">hsla(9, 100%, 64%, 0.8)</h3>
     <h3 style="background-color:hsla(9, 100%, 64%, 1);">hsla(9, 100%, 64%, 1)</h3>

</body>
</html>

hsla(9, 100%, 64%, 0)

hsla(9, 100%, 64%, 0.2)

hsla(9, 100%, 64%, 0.4)

hsla(9, 100%, 64%, 0.6)
