CSS Centering Elements

You can center elements horizontally, vertically, or both, using several different CSS methods — which one to use depends on the type of element and what you already know about its size.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .center {
             display: flex;
             justify-content: center;
             align-items: center;
             height: 150px;
             border: 3px solid green;
         }
     </style>
</head>
<body>
     <div class="center">
         <p>I am vertically and horizontally centered.</p>
     </div>
</body>
</html>

I am vertically and horizontally centered.

Tip: Flexbox (shown above) is the most modern and generally recommended way to center both horizontally and vertically at once — it's covered in more depth further down this page.

Horizontal Alignment

There are several ways to center an element horizontally, and the right one depends on what kind of element it is:

  • margin: auto - Center block elements
  • text-align: center - Center text inside an element
  • float or position - Align elements to the left or right

Center Align Block Elements

To horizontally center a block-level element (like a <div>), use margin: auto together with a defined width. Without a width, or with width: 100%, centering has no visible effect since the element already fills the container — the leftover space outside that width is what gets split equally between the left and right margins:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .center {
             margin: auto;
             width: 50%;
             border: 3px solid green;
             padding: 10px;
         }
     </style>
</head>
<body>
     <div class="center">
         <p>This div is centered.</p>
     </div>
</body>
</html>

This div is centered.

Center Align Text

To center just the text inside a block-level element, use text-align: center instead:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         p {
             text-align: center;
         }
     </style>
</head>
<body>
     <p>This text is centered.</p>
</body>
</html>

This text is centered.

Center Align an Image

To center an image, set its display to block (images are inline by default) and set margin-left and margin-right to auto:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         img {
             display: block;
             margin-left: auto;
             margin-right: auto;
             width: 40%;
         }
     </style>
</head>
<body>
     <img src="img_5terre.jpg" alt="Cinque Terre, Italy">
</body>
</html>

Left and Right Align - Using position

Use position: absolute with a left or right offset to align an element to one side. Keep in mind that an absolutely positioned element is removed from the normal document flow and can overlap other elements:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .right {
             position: absolute;
             right: 0px;
             width: 300px;
             border: 3px solid green;
             padding: 10px;
         }
     </style>
</head>
<body>
     <div class="right">
         <p>This div is right-aligned using position.</p>
     </div>
</body>
</html>

This div is right-aligned using position.

Left and Right Align - Using float

The float property can also align an element to the left or right, as covered in the previous float lesson. Remember that a floated element's parent container needs a clearfix (like overflow: auto) so it doesn't collapse:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .right {
             float: right;
             width: 300px;
             border: 3px solid green;
             padding: 10px;
         }
     </style>
</head>
<body>
     <div class="right">
         <p>This div is right-aligned using float.</p>
     </div>
</body>
</html>

This div is right-aligned using float.

Vertical Alignment

Vertical centering is trickier than horizontal centering, since block elements naturally stack rather than sit side by side. Three reliable methods: Flexbox, Grid, and position combined with transform.

Center Align with Flexbox

Setting justify-content: center and align-items: center on a flex container centers its content on both axes at once:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .center {
             display: flex;
             justify-content: center;
             align-items: center;
             height: 200px;
             border: 3px solid green;
         }
     </style>
</head>
<body>
     <div class="center">
         <p>I am vertically and horizontally centered.</p>
     </div>
</body>
</html>

I am vertically and horizontally centered.

Center Align with Grid

Setting place-items: center on a grid container does the same job as the flexbox combination above, in a single declaration:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .center {
             display: grid;
             place-items: center;
             height: 200px;
             border: 3px solid green;
         }
     </style>
</head>
<body>
     <div class="center">
         <p>I am vertically and horizontally centered.</p>
     </div>
</body>
</html>

I am vertically and horizontally centered.

Center Align with position and transform

For an element whose size isn't known in advance, combine position: absolute with top: 50%; left: 50% and transform: translate(-50%, -50%). The transform shifts the element back by half of its own width and height, which is what actually centers it — centering with percentages alone only aligns the element's top-left corner:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             position: relative;
             height: 200px;
             border: 3px solid green;
         }
         .container p {
             margin: 0;
             position: absolute;
             top: 50%;
             left: 50%;
             transform: translate(-50%, -50%);
         }
     </style>
</head>
<body>
     <div class="container">
         <p>I am vertically and horizontally centered.</p>
     </div>
</body>
</html>

I am vertically and horizontally centered.

Tip: See the CSS 2D Transforms lesson for more on what transform can do beyond centering.
