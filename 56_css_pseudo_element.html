CSS Pseudo-elements

A pseudo-element is a keyword added to a selector that lets you style a specific part of an element, rather than the whole thing. For example, it can style the first letter or first line of an element's text, insert content before or after an element's content, style list markers, or style text the user has selected.

The syntax uses a double colon :: between the selector and the pseudo-element name, to tell pseudo-elements apart from CSS classes:

selector::pseudo-element { property: value; }

The ::first-line Pseudo-element

The ::first-line pseudo-element styles only the first line of text inside an element, letting the rest of the paragraph render normally.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         p::first-line {
             color: #ff5722;
             font-variant: small-caps;
             font-size: 19px;
         }
     </style>
</head>
<body>

     <h2>Using ::first-line</h2>
     <p>The ::first-line pseudo-element styles the first line of a text. The rest of the text will not be affected. This is a long paragraph, used to demonstrate how the first-line pseudo-element works in a browser.</p>

</body>
</html>

Using ::first-line

The ::first-line pseudo-element styles the first line of a text. The rest of the text will not be affected. This is a long paragraph, used to demonstrate how the first-line pseudo-element works in a browser.

Note: ::first-line can only be applied to block-level elements.

The ::first-letter Pseudo-element

The ::first-letter pseudo-element styles only the first letter of text inside an element.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         p::first-letter {
             color: #ff5722;
             font-size: xx-large;
         }
     </style>
</head>
<body>

     <h2>Using ::first-letter</h2>
     <p>The ::first-letter pseudo-element styles the first letter of a text. The rest of the text will not be affected.</p>

</body>
</html>

Using ::first-letter

The ::first-letter pseudo-element styles the first letter of a text. The rest of the text will not be affected.

Note: ::first-letter can only be applied to block-level elements too.

Pseudo-elements and HTML Classes

Pseudo-elements can be combined with CSS classes, so the effect only applies to elements carrying that class instead of every element of that type on the page:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         p.intro::first-letter {
             color: #ff0000;
             font-size: 200%;
         }
     </style>
</head>
<body>

     <p class="intro">This paragraph carries the "intro" class, so only its first letter is enlarged and coloured.</p>
     <p>This plain paragraph has no class, so it is left untouched.</p>

</body>
</html>

This paragraph carries the "intro" class, so only its first letter is enlarged and coloured.

This plain paragraph has no class, so it is left untouched.

The ::before Pseudo-element

The ::before pseudo-element inserts content immediately before the content of the selected element. It needs the content property to be set — even to an empty string — otherwise nothing is inserted.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         h3::before {
             content: url(smiley.gif);
         }
     </style>
</head>
<body>

     <h2>Using ::before</h2>
     <h3>This is a heading</h3>
     <p>The ::before pseudo-element inserts content before the content of an element.</p>

</body>
</html>

Using ::before

This is a heading

The ::before pseudo-element inserts content before the content of an element.

Note: The reference example inserts an image (smiley.gif); this page substitutes an emoji character via content: "\1F600" so no extra image file is required.

The ::marker Pseudo-element

The ::marker pseudo-element lets you style the marker box of a list item — the bullet of an unordered list, or the number of an ordered list.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         ::marker {
             color: #ff5722;
             font-size: 23px;
         }
     </style>
</head>
<body>

     <h2>Using ::marker</h2>
     <ul>
         <li>Coffee</li>
         <li>Tea</li>
         <li>Milk</li>
     </ul>
     <ol>
         <li>First</li>
         <li>Second</li>
         <li>Third</li>
     </ol>

</body>
</html>

Using ::marker

  • Coffee
  • Tea
  • Milk
  1. First
  2. Second
  3. Third

The ::selection Pseudo-element

The ::selection pseudo-element styles the portion of text a user has selected (highlighted) by clicking and dragging the mouse, or via keyboard selection.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         ::selection {
             color: #ffffff;
             background: #ff5722;
         }
     </style>
</head>
<body>

     <h2>Using ::selection</h2>
     <p>Select (highlight) some of this text with your mouse to see the ::selection style applied.</p>

</body>
</html>

Using ::selection

Select (highlight) some of this text with your mouse to see the ::selection style applied.
