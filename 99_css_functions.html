CSS Functions

CSS functions are built-in operations used as values inside a declaration — they compute, transform, or reference something rather than being a static keyword. This page is an A-Z index of CSS functions, each with a short description — a quick lookup rather than a tutorial. For functions already covered with full examples elsewhere in this course (like calc(), var(), min()/max()/clamp(), and the gradient functions), see that earlier lesson for worked demos.

Function Categories at a Glance

The 80 functions above fall into a handful of natural groups:

CategoryExamples
Mathcalc(), min(), max(), clamp(), sqrt(), pow(), round(), mod(), rem()
Trigonometrysin(), cos(), tan(), asin(), acos(), atan(), atan2(), hypot()
Colorrgb(), hsl(), hwb(), lab(), lch(), oklab(), oklch(), color-mix()
Gradientslinear-gradient(), radial-gradient(), conic-gradient(), and their repeating-* variants
Filtersblur(), brightness(), contrast(), grayscale(), invert(), sepia(), saturate(), hue-rotate(), drop-shadow(), opacity()
2D/3D Transformstranslate(), rotate(), scale(), skew(), their axis-specific variants, matrix(), perspective()
Shapescircle(), ellipse(), polygon(), inset(), xywh()
Grid sizingrepeat(), minmax(), fit-content()
Counters & contentcounter(), counters(), attr(), url(), var()
Animation timingcubic-bezier(), steps()

Note: A function always ends in parentheses, which is what tells them apart from plain keyword values — center is a keyword, but translateX(10px) is a function call that computes a value.
