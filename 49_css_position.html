CSS Positioning

With CSS positioning, you can override the normal document flow and control exactly where an element appears.

The CSS position Property

The position property specifies the positioning type for an element.

This property can have one of the following values:

  • static - This is default. Element is positioned according to the normal document flow
  • relative - Element is positioned relative to its normal position in the document flow
  • fixed - Element is positioned relative to the viewport
  • absolute - Element is positioned relative to the nearest positioned ancestor
  • sticky - Element toggles between a relative and fixed position, depending on the scroll position

Elements are then positioned to their final location with the top, bottom, left, and right properties.

position: static

This is the default value — every element is static unless set otherwise. Static elements are not affected by top, bottom, left, or right; they simply follow the normal page flow.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div.static_demo { position: static; border: 3px solid #73AD21; padding: 10px; }
     </style>
</head>
<body>
     <div class="static_demo">This div has position: static — it sits exactly where it would in normal flow.</div>
</body>
</html>
This div has position: static — it sits exactly where it would in normal flow.

position: relative

An element with position: relative is positioned relative to its own normal position. Setting an offset (like left: 30px) shifts the element away from where it would normally sit, without affecting the layout of surrounding elements — the space it originally occupied is preserved:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div.relative_demo { position: relative; left: 30px; border: 3px solid #73AD21; padding: 10px; }
     </style>
</head>
<body>
     <div class="relative_demo">This div has position: relative and left: 30px — shifted 30px from its normal spot.</div>
</body>
</html>
This div has position: relative and left: 30px — shifted 30px from its normal spot.

position: fixed

An element with position: fixed is positioned relative to the viewport, so it stays in the same place even when the page scrolls. A fixed element is removed from the normal flow and leaves no gap behind. (Scaled down here into a bordered demo box instead of the real viewport, so the effect stays visible on the page.)

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div.fixed_demo {
             position: absolute;
             bottom: 10px;
             right: 10px;
             width: 220px;
         }
     </style>
</head>
<body>
     <div class="fixed_demo_wrap">
         <div class="fixed_demo">This box uses position: fixed with bottom: 0; right: 0 — pinned to a corner regardless of scrolling.</div>
     </div>
</body>
</html>
This box uses position: fixed with bottom: 0; right: 0 — pinned to a corner regardless of scrolling.

position: absolute

An element with position: absolute is positioned relative to its nearest ancestor that has a position other than static (often a relative parent). If no such ancestor exists, it falls back to the document body. Absolute elements are removed from the normal flow and can overlap other elements:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div.relative_container { position: relative; width: 100%; height: 200px; border: 3px solid green; padding: 10px; }
         div.absolute_demo { position: absolute; top: 80px; right: 20px; width: 200px; border: 3px solid red; padding: 10px; background-color: #fff; }
     </style>
</head>
<body>
     <div class="relative_container">
         This is the positioned ancestor (position: relative).
         <div class="absolute_demo">position: absolute, top: 80px, right: 20px — overlaps the parent's content.</div>
     </div>
</body>
</html>
This is the positioned ancestor (position: relative).
position: absolute, top: 80px, right: 20px — overlaps the parent's content.

position: sticky

An element with position: sticky toggles between relative and fixed depending on scroll position: it behaves normally until the scroll reaches a given offset, then sticks in place. A top, right, bottom, or left offset is required for it to work. Scroll the box below to see it in action:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .sticky_demo_wrap { height: 220px; overflow-y: auto; border: 1px dashed #aaa; }
         div.sticky_demo { position: sticky; top: 0; background-color: #04AA6D; color: white; border: 2px solid #4CAF50; padding: 8px 10px; }
     </style>
</head>
<body>
     <div class="sticky_demo_wrap">
         <div class="sticky_demo">I stick to the top once you scroll past me</div>
         <p>Scroll content line 1</p>
         <p>Scroll content line 2</p>
         <p>Scroll content line 3</p>
         <p>Scroll content line 4</p>
         <p>Scroll content line 5</p>
         <p>Scroll content line 6</p>
         <p>Scroll content line 7</p>
         <p>Scroll content line 8</p>
     </div>
</body>
</html>
