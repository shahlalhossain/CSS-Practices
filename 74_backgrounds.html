CSS Backgrounds

Earlier lessons in this series (Background Color, Background Image, Background Repeat, Background Attachment, Background Shorthand) already covered the one-image-at-a-time basics. This lesson covers the parts of CSS3 backgrounds that go beyond that: stacking multiple background images on a single element, controlling their exact size with background-size, and controlling how the positioning/clipping area is measured with background-origin and background-clip.

CSS Multiple Backgrounds

CSS allows more than one background image for an element, layered on top of each other. The first image listed in background-image sits on top, and each subsequent one sits further back. background-position and background-repeat can also take a comma-separated list, matched up with each image in the same order.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #example1 {
             background-image: url(img_tree.png), url(pineapple.jpg);
             background-position: right bottom, left top;
             background-repeat: no-repeat, repeat;
             height: 200px;
         }
     </style>
</head>
<body>

     <h1>Multiple Background Images</h1>
     <p>Here, we use two background images, one tree in the bottom-right corner, and a repeated pineapple pattern behind it:</p>

     <div id="example1"></div>

</body>
</html>

Note: The shorthand background property can also combine all of this in one declaration: background: url(img_tree.png) right bottom no-repeat, url(pineapple.jpg) left top repeat; — each comma-separated group is one full "layer" (image, position, repeat), read in the same order as the images.

CSS Background-size

The background-size property lets a background image be resized to fit its element, instead of showing at its native pixel size. It accepts length values (e.g. 100px 80px), percentages of the element's own box, or the keywords contain (scale the image up to the largest size that still fits entirely inside the box) and cover (scale the image up to fully cover the box, cropping any overflow).

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #bgsize1 {
             background: url(img_mountains.jpg);
             background-size: 100px 80px;
             background-repeat: no-repeat;
             border: 1px solid black;
             height: 150px;
         }

         #bgsize2 {
             background: url(img_mountains.jpg);
             background-size: cover;
             background-repeat: no-repeat;
             border: 1px solid black;
             height: 150px;
         }
     </style>
</head>
<body>

     <h2>background-size: 100px 80px</h2>
     <div id="bgsize1"></div>

     <h2>background-size: cover</h2>
     <div id="bgsize2"></div>

</body>
</html>

background-size: 100px 80px

background-size: cover

Note: background-size can also be set globally for the whole page via the body selector, which is a common way to build a full-page background photo that always fills the viewport with background-size: cover; combined with background-attachment: fixed;.

CSS Background-origin and Background-clip

The background-origin property sets the positioning area of the background image — the coordinate 0 0 that background-position measures from. It takes three values:

  • padding-box — default; position is relative to the padding box
  • border-box — position is relative to the border box
  • content-box — position is relative to the content box

background-clip is the related property that controls how far the background (color or image) is allowed to extend, before being clipped off. It accepts the same border-box / padding-box / content-box keywords, plus text (clips the background to the shape of the foreground text).

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #origin1 {
             border: 10px dashed black;
             padding: 25px;
             background: url(img_tree.png);
             background-repeat: no-repeat;
             background-origin: content-box;
         }

         #clip1 {
             border: 10px dashed black;
             padding: 25px;
             background: url(img_tree.png);
             background-repeat: no-repeat;
             background-clip: content-box;
         }
     </style>
</head>
<body>

     <h2>background-origin: content-box</h2>
     <div id="origin1"></div>

     <h2>background-clip: content-box</h2>
     <div id="clip1"></div>

</body>
</html>

background-origin: content-box

background-clip: content-box

Note: In the first box, the tree image starts further in from the dashed border because its origin is measured from the content box, not the padding edge. In the second box, the image itself is the same, but any part of it that would fall under the padding area is clipped away entirely rather than just repositioned — compare the two outputs closely against the "padding-box" default to see the difference.

CSS Background Properties

Property Description
backgroundShorthand for setting all background properties in one declaration
background-colorSpecifies the background color of an element
background-imageSpecifies one or more background images for an element
background-positionSpecifies the position of a background image
background-repeatSets how a background image will be repeated
background-attachmentSets whether a background image scrolls with the page or is fixed
background-sizeSpecifies the size of the background image(s)
background-originSpecifies the positioning area of the background image(s)
background-clipSpecifies the painting area of the background image(s)
