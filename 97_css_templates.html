CSS Layout Templates

W3Schools offers a set of free, responsive starter templates, built entirely with the techniques already covered in this CSS Responsive section — plain HTML and CSS, no framework required. Each one can be freely modified, saved, and reused as the starting point for a real project. The templates fall into four layout shapes: a header with equal columns and a footer; a header with unequal columns and a footer; a top navigation bar with content; and a side navigation with content. The first two shapes are each shown three times below, built with three different layout techniques — float, flexbox, and grid — so the same visual result can be compared across approaches.

Header, Equal Columns and Footer — Float

Three equal-width columns, floated left and cleared with a ::after clearfix on the row, stack to full width below 600px:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <style>
         * { box-sizing: border-box; }
         body { font-family: Arial, Helvetica, sans-serif; margin: 0; }
         .header, .footer { background-color: #f1f1f1; text-align: center; }
         .header { padding: 30px; font-size: 35px; }
         .footer { padding: 10px; }
         .column { float: left; width: 33.33%; padding: 10px; height: 300px; }
         .row::after { content: ""; display: table; clear: both; }
         @media (max-width: 600px) {
             .column { width: 100%; }
         }
     </style>
</head>
<body>
     <div class="header"><h2>Header</h2></div>
     <div class="row">
         <div class="column" style="background:#aaa;">Column</div>
         <div class="column" style="background:#bbb;">Column</div>
         <div class="column" style="background:#ccc;">Column</div>
     </div>
     <div class="footer"><p>Footer</p></div>
</body>
</html>

Header, Equal Columns and Footer — Grid

The same layout again, this time with display: grid and named grid-template-areas for the header, three columns, and footer:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <style>
         * { box-sizing: border-box; }
         body { font-family: Arial, Helvetica, sans-serif; margin: 0; }
         .grid-container {
             display: grid;
             grid-template-areas:
                 "header header header"
                 "left middle right"
                 "footer footer footer";
         }
         .header { grid-area: header; background-color: #f1f1f1; padding: 30px; text-align: center; font-size: 35px; }
         .footer { grid-area: footer; background-color: #f1f1f1; padding: 10px; text-align: center; }
         .left { grid-area: left; padding: 10px; height: 300px; }
         .middle { grid-area: middle; padding: 10px; height: 300px; }
         .right { grid-area: right; padding: 10px; height: 300px; }
         @media (max-width: 600px) {
             .grid-container {
                 grid-template-areas: "header" "left" "middle" "right" "footer";
             }
         }
     </style>
</head>
<body>
     <div class="grid-container">
         <div class="header"><h2>Header</h2></div>
         <div class="left" style="background:#aaa;">Column</div>
         <div class="middle" style="background:#bbb;">Column</div>
         <div class="right" style="background:#ccc;">Column</div>
         <div class="footer"><p>Footer</p></div>
     </div>
</body>
</html>

Note: All three examples above produce the same visual result from a very different mechanism — float needs a manual clearfix, flexbox distributes space along one axis with flex values, and grid names each region up front with grid-template-areas. Modern layouts typically reach for flexbox or grid; float is shown mainly because it's still common in older codebases.

Topnav, Content and Footer

The third template shape: a horizontal navigation bar built the same way as the earlier Horizontal Nav Bar lesson (floated links on a dark background, with a clearfix), sitting above a content block and a plain footer:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <style>
         * { box-sizing: border-box; }
         body { font-family: Arial, Helvetica, sans-serif; margin: 0; }
         .topnav { overflow: hidden; background-color: #333; }
         .topnav a { float: left; display: block; color: #f2f2f2; text-align: center; padding: 14px 16px; text-decoration: none; }
         .topnav a:hover { background-color: #ddd; color: black; }
         .content { background-color: #ddd; padding: 10px; height: 200px; }
         .footer { background-color: #f1f1f1; padding: 10px; }
     </style>
</head>
<body>
     <div class="topnav">
         <a href="#">Link</a>
         <a href="#">Link</a>
         <a href="#">Link</a>
     </div>
     <div class="content">
         <h2>CSS Template</h2>
         <p>This is a responsive page with a top navigation bar.</p>
     </div>
     <div class="footer">
         <p>Footer</p>
     </div>
</body>
</html>

Sidenav and Content

The fourth template shape: a fixed-position side navigation pinned to the left edge of the viewport, with the main content pushed clear of it using margin-left:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <style>
         * { box-sizing: border-box; }
         body { margin: 0; font-family: Arial, Helvetica, sans-serif; }
         .sidenav {
             position: fixed; top: 0; left: 0; height: 100%; width: 200px;
             background-color: #111; overflow-x: hidden;
         }
         .sidenav a { display: block; padding: 16px; text-decoration: none; color: white; }
         .sidenav a:hover { background-color: #ddd; color: black; }
         .content { margin-left: 200px; padding: 10px 20px; }
     </style>
</head>
<body>
     <div class="sidenav">
         <a href="#">Link</a>
         <a href="#">Link</a>
         <a href="#">Link</a>
     </div>
     <div class="content">
         <h2>CSS Template</h2>
         <p>This is a responsive page with a sidenav.</p>
     </div>
</body>
</html>

CSS Template

This is a responsive page with a sidenav.

Note: In the real template, the sidenav's position: fixed is relative to the whole browser viewport, so it stays in view while the page scrolls. It's scoped to the small bordered box above instead of the real page here, purely so the demo stays contained — the position/margin-left mechanics are otherwise identical. Unlike the other three template shapes, this one and the topnav template have no responsive breakpoint at all in the original: the sidenav keeps its fixed 200px width and the content area simply gets narrower on small screens.
