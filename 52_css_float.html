The CSS float Property

The float property specifies how an element should float within its container.

It places an element on the left or right side of its container, allowing text and inline elements to wrap around it.

The float property can have one of the following values:

  • left - The element floats to the left of its container
  • right - The element floats to the right of its container
  • none - Default. The element does not float and is displayed just where it occurs in the text
  • inherit - The element inherits the float value of its parent

Tip: The float property is often used to wrap text around images!

float: right

With float: right, the image is pushed to the right edge of its container, and the surrounding text flows around its left side:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .float_right_demo { overflow: auto; }
         .float_right_demo img { float: right; width: 100px; margin-left: 15px; }
     </style>
</head>
<body>
     <div class="float_right_demo">
         <img src="pineapple.jpg" alt="Pineapple">
         In this paragraph, the image floats to the right, and the text wraps around its left edge. This is one of the oldest CSS layout tricks, long used in print-style web articles to run text beside an illustration or photo instead of leaving the image isolated on its own line.
     </div>
</body>
</html>
In this paragraph, the image floats to the right, and the text wraps around its left edge. This is one of the oldest CSS layout tricks, long used in print-style web articles to run text beside an illustration or photo instead of leaving the image isolated on its own line.

float: left

With float: left, the image moves to the left edge, and text flows around its right side instead:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .float_left_demo { overflow: auto; }
         .float_left_demo img { float: left; width: 100px; margin-right: 15px; }
     </style>
</head>
<body>
     <div class="float_left_demo">
         <img src="pineapple.jpg" alt="Pineapple">
         In this paragraph, the image floats to the left, and the text wraps around its right edge instead. The rest of the layout logic is identical to float: right — only the side changes.
     </div>
</body>
</html>
In this paragraph, the image floats to the left, and the text wraps around its right edge instead. The rest of the layout logic is identical to float: right — only the side changes.

float: none

This is the default. The element is not floated — it displays right where it appears in the normal flow, with no text wrapping around it:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .float_none_demo { overflow: auto; }
         .float_none_demo img { float: none; width: 100px; }
     </style>
</head>
<body>
     <div class="float_none_demo">
         <img src="pineapple.jpg" alt="Pineapple">
         With float: none, the image is simply inline/block content like any other element — the text here does not wrap around it.
     </div>
</body>
</html>
With float: none, the image is simply inline/block content like any other element — the text here does not wrap around it.

CSS Float for Layout

Floats are also used to build horizontal layouts. Block-level <div> elements normally stack vertically and take the full available width — floating them left instead makes them sit side-by-side:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .float_layout_demo { overflow: auto; }
         .float_layout_demo div { float: left; padding: 15px; color: white; text-align: center; }
         .div1 { background: red; }
         .div2 { background: yellow; color: #333; }
         .div3 { background: green; }
     </style>
</head>
<body>
     <div class="float_layout_demo">
         <div class="div1">div1</div>
         <div class="div2">div2</div>
         <div class="div3">div3</div>
     </div>
</body>
</html>
div1
div2
div3

Note: This float-based layout technique is largely obsolete now that Flexbox and Grid exist, but it's still common in older codebases and worth recognizing.

The CSS clear Property

The clear property specifies what should happen with the element that is NEXT to a floating element.

The clear property prevents elements from wrapping around or beside the floated content.

This property can have one of the following values:

  • none - Default. Allows elements to float on either side
  • left - The element is pushed below floated elements on its left side
  • right - The element is pushed below floated elements, on its right side
  • both - The element is pushed below floated elements, on both its left and right side
  • inherit - The element inherits the clear value from its parent

Here's a practical demonstration — div2 below has clear: left set, forcing it below the floated div1 instead of wrapping up beside it:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .clear_demo_wrap { border: 1px dashed #aaa; padding: 10px; }
         .clear_demo_float { float: left; width: 150px; padding: 10px; background-color: lightblue; }
         .clear_demo_none { background-color: #f2f2f2; padding: 10px; }
         .clear_demo_cleared { clear: left; background-color: #f2f2f2; padding: 10px; }
     </style>
</head>
<body>
     <div class="clear_demo_wrap">
         <div class="clear_demo_float">Floated div (float: left)</div>
         <div class="clear_demo_none">No clear — this div wraps up beside the float instead of starting below it.</div>
     </div>
     <br>
     <div class="clear_demo_wrap">
         <div class="clear_demo_float">Floated div (float: left)</div>
         <div class="clear_demo_cleared">clear: left — this div is forced below the float instead.</div>
     </div>
</body>
</html>

No clear — this div wraps up beside the float instead of starting below it.

Floated div (float: left)
clear: left — this div is forced below the float instead.

The Clearfix Hack

When every child inside a container is floated, the container itself collapses to zero height — because floated elements are taken out of the normal flow, the parent no longer "sees" them. Here, the green-bordered container has no floated children clearing inside it, so it collapses around them:

Floating box 1
Floating box 2

The fix is to add a ::after pseudo-element to the container that clears both floats, forcing the container to properly enclose its floated children — commonly called the "clearfix" hack:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .clearfix_fixed { border: 3px solid #4CAF50; }
         .clearfix_fixed::after { content: ""; clear: both; display: table; }
         .clearfix_float { float: left; width: 150px; padding: 10px; background-color: lightblue; margin: 10px; }
     </style>
</head>
<body>
     <div class="clearfix_fixed">
         <div class="clearfix_float">Floating box 1</div>
         <div class="clearfix_float">Floating box 2</div>
     </div>
</body>
</html>
Floating box 1
Floating box 2

Note: Setting overflow: auto (or hidden) on the parent is a simpler alternative that also clears floats, since it forces the container to establish a new block formatting context — but the ::after clearfix is the more explicit, widely documented solution and avoids any unwanted scrollbars or clipped content.

Create Equal Width Boxes

With float, it's easy to lay out boxes of content side by side using percentage widths — three boxes at 33.33%, four at 25%, two at 50%, and so on. Adding box-sizing: border-box keeps padding and borders inside the declared width, so the boxes don't overflow and break the layout:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         * { box-sizing: border-box; }
         .equal_width_demo { overflow: auto; }
         .box { float: left; width: 33.33%; padding: 20px; color: white; text-align: center; }
         .box1 { background: #4070f4; }
         .box2 { background: #04AA6D; }
         .box3 { background: #73AD21; }
     </style>
</head>
<body>
     <div class="equal_width_demo">
         <div class="box box1">Box 1</div>
         <div class="box box2">Box 2</div>
         <div class="box box3">Box 3</div>
     </div>
</body>
</html>

Images Side By Side

The same technique works for an image gallery: wrap each image in a container, float the containers left, and give each one a percentage width:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         * { box-sizing: border-box; }
         .img_gallery_demo { overflow: auto; }
         .img_container { float: left; width: 33.33%; padding: 5px; }
         .img_container img { width: 100%; }
     </style>
</head>
<body>
     <div class="img_gallery_demo">
         <div class="img_container"><img src="img_5terre.jpg" alt="Cinque Terre, Italy"></div>
         <div class="img_container"><img src="img_forest.jpg" alt="Forest"></div>
         <div class="img_container"><img src="img_mountains.jpg" alt="Mountains"></div>
     </div>
</body>
</html>

Boxes With Equal Heights

Floated boxes don't automatically match each other's height — if one box has more content than its neighbors, it simply grows taller on its own. A fixed height can force equal heights, but breaks down the moment content doesn't fit, especially on smaller screens:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .box {
             height: 500px;
             /* breaks if content overflows */
         }
     </style>
</head>
<body>
     <div class="box">...</div>
</body>
</html> 		A fixed height is a fragile fix — it only works as long as every box's content happens to fit.

Note: Float was never really designed for equal-height columns. CSS Flexbox solves this properly — a flex container automatically stretches every item to match the height of the tallest one, with no fixed height or guesswork needed.

Float-based Navigation Menu

Another classic use of float: turning a plain <ul> list into a horizontal navigation bar, by floating each <li> left:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .nav_menu_demo ul { list-style-type: none; margin: 0; padding: 0; overflow: auto; background-color: #333; }
         .nav_menu_demo li { float: left; }
         .nav_menu_demo li a { display: block; color: white; text-align: center; padding: 14px 16px; text-decoration: none; }
         .nav_menu_demo li a:hover { background-color: #4070f4; }
     </style>
</head>
<body>
     <nav class="nav_menu_demo">
         <ul>
             <li><a href="#">Home</a></li>
             <li><a href="#">News</a></li>
             <li><a href="#">Contact</a></li>
             <li><a href="#">About</a></li>
         </ul>
     </nav>
</body>
</html>
  • Home
  • News
  • Contact
  • About

Note: The <ul> needs overflow: auto (a clearfix) so it doesn't collapse around its floated <li> children — the same problem covered earlier in this lesson.
