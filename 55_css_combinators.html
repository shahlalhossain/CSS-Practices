CSS Combinators

A combinator explains the relationship between two or more selectors. There are four different combinators in CSS:

  • Descendant combinator (space)
  • Child combinator (>)
  • Next sibling combinator (+)
  • Subsequent-sibling combinator (~)

Descendant Combinator

The descendant combinator (a single space) matches all elements that are descendants of a specified element — children, grandchildren, and so on, no matter how deeply nested. The example below selects all <p> elements inside a <div> element:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div p {
             background-color: yellow;
         }
     </style>
</head>
<body>
     <p>Paragraph 1 in the div.</p>
     <div>
         <p>Paragraph 1 in the div.</p>
         <p>Paragraph 2 in the div.</p>
         <section>
             <p>Paragraph 3 in the div (inside a section).</p>
         </section>
     </div>
     <p>Paragraph 4. Not in a div.</p>
     <p>Paragraph 5. Not in a div.</p>
</body>
</html>

Paragraph 1. Not in a div.

Paragraph 1 in the div.

Paragraph 2 in the div.

Paragraph 3 in the div (inside a section).

Paragraph 4. Not in a div.

Paragraph 5. Not in a div.

Note: Paragraph 3 is highlighted too, even though it's wrapped in a <section> — the descendant combinator matches at any depth, not just direct children.

Child Combinator

The child combinator (>) selects all elements that are the direct children of a specified element — only one level deep, unlike the descendant combinator. The example below selects all <p> elements that are direct children of a <div> element:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div > p {
             background-color: yellow;
         }
     </style>
</head>
<body>
     <div>
         <p>Paragraph 1 (direct child).</p>
         <p>Paragraph 2 (direct child).</p>
         <section>
             <p>Paragraph 3 (grandchild, inside a section).</p>
         </section>
         <p>Paragraph 4 (direct child).</p>
     </div>
     <p>Paragraph 5. Not in a div.</p>
</body>
</html>

Paragraph 1 (direct child).

Paragraph 2 (direct child).

Paragraph 3 (grandchild, inside a section).

Paragraph 4 (direct child).

Paragraph 5. Not in a div.

Note: Paragraph 3 is NOT highlighted this time — it's a grandchild of the <div>, nested one level deeper inside the <section>, so the child combinator skips it.

Next Sibling Combinator

The next sibling combinator (+) selects an element that is immediately preceded by a specified element — both must share the same parent. The example below selects the first <p> element that comes immediately after a <div>:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div + p {
             background-color: yellow;
         }
     </style>
</head>
<body>
     <p>Paragraph 1.</p>
     <div>
         <p>Paragraph 2 (inside the div).</p>
     </div>
     <p>Paragraph 3 (first sibling right after the div).</p>
     <p>Paragraph 4 (follows another p, not the div).</p>
</body>
</html>

Paragraph 1.

Paragraph 2 (inside the div).

Paragraph 3 (first sibling right after the div).

Paragraph 4 (follows another p, not the div).

Note: Only Paragraph 3 is highlighted. Paragraph 4 is also a sibling of the <div>, but it doesn't come immediately after it — Paragraph 3 is in the way — so the next sibling combinator only ever matches one element.

Subsequent-sibling Combinator

The subsequent-sibling combinator (~) selects all elements that are siblings of a specified element and come after it, no matter how many other elements sit in between. The example below selects every <p> element that is a sibling of, and appears after, a <div>:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         div ~ p {
             background-color: yellow;
         }
     </style>
</head>
<body>
     <p>Paragraph 1.</p>
     <div>
         <p>Paragraph 2.</p>
     </div>
     <p>Paragraph 3.</p>
     <code>Some code.</code>
     <p>Paragraph 4.</p>
</body>
</html>

Paragraph 1.

Paragraph 2.

Paragraph 3.

Some code.

Paragraph 4.

Note: Both Paragraph 3 and Paragraph 4 are highlighted, even with the <code> element sitting between them — unlike +, the ~ combinator doesn't require the match to be immediately adjacent, only that it comes after and shares the same parent.

CSS Combinators Reference

Combinator Description
element elementDescendant combinator — matches all elements that are descendants of a specified element
element > elementChild combinator — matches all elements that are direct children of a specified element
element + elementNext sibling combinator — matches an element that is directly after a specified element, sharing the same parent
element ~ elementSubsequent-sibling combinator — matches every element that is a sibling of, and comes after, a specified element
