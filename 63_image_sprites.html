CSS Image Sprites

An image sprite is a single image file that bundles several smaller images together. Combining images this way cuts down the number of server requests a page needs and often saves bandwidth, since one larger file loads faster than many small ones. Showing just one piece of the sprite is done with the background-image and background-position properties.

Image Sprites - Simple Example

Instead of using three separate images for a Home, Previous, and Next icon, this sprite sheet (img_navsprites.gif) holds all three side by side in one file:

With CSS, only the part of the sprite image we need is shown, by setting a fixed element size and shifting the background with a negative background-position.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #home {
             width: 46px;
             height: 44px;
             background: url(img_navsprites.gif) 0 0;
         }
     </style>
</head>
<body>

     <div id="home"></div>

</body>
</html>

Note: The width/height is set to match the size of the part of the image we want to show (here the Home icon, 46×44 pixels), and overflow of the rest of the sprite sheet is clipped off automatically since the element is smaller than the full background image.

Image Sprites - Create a Navigation List

The same sprite sheet can be used to build a horizontal icon navigation bar: an unordered list is positioned with position: relative, each <li> is positioned absolutely at the left offset where its icon should sit, and the anchor inside each item is sized to exactly one icon with its own slice of the background.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #navlist {
             position: relative;
         }
         #navlist li {
             margin: 0;
             padding: 0;
             list-style: none;
             position: absolute;
             top: 0;
         }
         #home { left: 0px; }
         #prev { left: 63px; }
         #next { left: 129px; }

         #navlist li, #navlist a {
             height: 44px;
             display: block;
         }

         #home a { width: 46px; background: url('img_navsprites.gif') 0 0; }
         #prev a { width: 43px; background: url('img_navsprites.gif') -47px 0; }
         #next a { width: 43px; background: url('img_navsprites.gif') -91px 0; }

         #home a:hover { background: url('img_navsprites_hover.gif') 0 -45px; }
         #prev a:hover { background: url('img_navsprites_hover.gif') -47px -45px; }
         #next a:hover { background: url('img_navsprites_hover.gif') -91px -45px; }
     </style>
</head>
<body>

     <ul id="navlist">
         <li id="home"><a href="default.asp"></a></li>
         <li id="prev"><a href="css_intro.asp"></a></li>
         <li id="next"><a href="css_syntax.asp"></a></li>
     </ul>

</body>
</html>

Note: Hover your mouse over each icon in the output column — the :hover rule swaps in a second sprite sheet (img_navsprites_hover.gif) whose matching icon sits 45 pixels lower, so only the background-position y-offset changes on hover, not the image itself.
