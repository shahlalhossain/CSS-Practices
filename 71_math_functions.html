CSS Math Functions

CSS math functions let a property value be computed from an expression instead of a single fixed number. This lesson covers four of them: calc(), max(), min(), and clamp().

The calc() Function

The calc() function performs a calculation to produce a property value, using the operators +, -, *, and /. Its real strength is mixing unlike units in a single expression — something you simply cannot do by just writing a value directly, e.g. sizing something to "100% of the parent, minus a fixed 100px".

Syntax: calc(expression)

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #div1 {
             margin: auto;
             width: calc(100% - 100px);
             height: calc(30vh + 50px);
             border: 1px solid black;
             padding: 10px;
         }
     </style>
</head>
<body>

     <h2>The calc() Function</h2>
     <p>Here, #div1 is 100px narrower than its full containing width, and 50px taller than 30% of the viewport height.</p>
     <p>Resize the browser window to see the effect!</p>

     <div id="div1">Some text...</div>

</body>
</html>
Some text...

Note: Always put a space on both sides of the + and - operators (calc(100% - 100px), not calc(100%-100px)) — without it, the browser cannot tell where the first value ends, and the whole declaration is dropped as invalid.

The max() Function

max() takes a comma-separated list of values and uses the largest one. It's useful when you want a size to never shrink below some minimum while still being able to grow with its container.

Syntax: max(value1, value2, ...)

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #div1 {
             height: 100px;
             width: max(50%, 300px);
             border: 1px solid black;
             padding: 10px;
         }
     </style>
</head>
<body>

     <h2>The max() Function</h2>
     <p>Use max() to set the width of #div1 to whichever is largest: 50% or 300px.</p>
     <p>Resize the browser window to see the effect!</p>

     <div id="div1">Some text...</div>

</body>
</html>
Some text...

Note: In the output column here, the panel is narrower than a full page, so 50% of it is less than 220px — which means max() picks the fixed 220px floor instead. Widen the browser (or imagine this on a full page) and once 50% of the container exceeds that floor, the percentage takes over.

The min() Function

min() is the mirror image of max(): it takes a comma-separated list of values and uses the smallest one. It's useful for capping a size so it never grows past some fixed maximum, while still shrinking with its container on small screens.

Syntax: min(value1, value2, ...)

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         #div1 {
             height: 100px;
             width: min(50%, 300px);
             border: 1px solid black;
             padding: 10px;
         }
     </style>
</head>
<body>

     <h2>The min() Function</h2>
     <p>Use min() to set the width of #div1 to whichever value is smallest: 50% or 300px.</p>
     <p>Resize the browser window to see the effect.</p>

     <div id="div1">Some text...</div>

</body>
</html>
Some text...

Note: Here it's the opposite case from the max() example above: since 50% of this narrow panel is less than 220px, min() picks the percentage. On a wide page where 50% would exceed 220px, the fixed 220px ceiling would be used instead.

The clamp() Function

clamp() combines a minimum, a preferred, and a maximum value into one expression, so a size can scale fluidly with the viewport while never going outside a safe range: if the preferred value falls between the minimum and maximum, it's used as-is; if it would go below the minimum, the minimum is used instead; if it would go above the maximum, the maximum is used instead.

Syntax: clamp(minimum, preferred, maximum) — all three arguments are required.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         h2 {
             font-size: clamp(1.5rem, 5vw, 3rem);
         }

         div {
             border: 1px solid green;
             padding: 10px;
             font-size: clamp(1rem, 2.5vw, 2rem);
             width: clamp(200px, 50%, 600px);
         }
     </style>
</head>
<body>

     <h2>The clamp() Function</h2>
     <p>Resize the window to see the effect!</p>

     <div>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Nulla ac laoreet quam, id aliquet nisl. Etiam id eros ligula.</div>

</body>
</html>

The clamp() Function

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Nulla ac laoreet quam, id aliquet nisl. Etiam id eros ligula.

Note: Think of clamp() as max(minimum, min(preferred, maximum)) rolled into one function — it's commonly used for fluid typography, sizing text so it grows with the viewport on larger screens without ever becoming unreadably small or absurdly large.
