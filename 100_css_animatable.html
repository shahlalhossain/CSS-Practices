CSS Animatable

Animatable properties are ones whose value can change gradually from a start value to an end value, instead of jumping straight from one to the other. This is what makes transition and @keyframes animation look smooth — the browser computes in-between frames along the way. A property that is NOT animatable still responds to transition/animation rules, but it simply flips between its states with no smooth in-between.

Not every value type can be interpolated the same way: numbers, lengths, percentages, and colors all have a well-defined "halfway point," so they animate smoothly. Keywords like none or block don't — there's no meaningful midpoint between them, so a property built only from keywords (like display) cannot animate at all.

Animatable Properties (A-Z)

The "Animates As" column shows what kind of value is actually being interpolated — most animatable properties boil down to a number, a length/percentage, or a color underneath, even when the property itself has a different name.

Trying It Yourself

A quick way to see animatability in action: set a transition on a property from the list above, then change that property's value (e.g. on :hover). If the property is animatable, the change eases smoothly over the transition's duration; if it isn't, the change happens instantly regardless of the duration you set.

<!DOCTYPE html>
<html>
<head>
     <style>
         .box {
             width: 100px;
             height: 100px;
             background-color: #04AA6D;
             transition: background-color 1s, border-radius 1s;
         }
         .box:hover {
             background-color: #4070f4;
             border-radius: 50%;
         }
     </style>
</head>
<body>
     <div class="box"></div>
</body>
</html>

Hover the box — color and corner radius ease smoothly, because both background-color and border-radius are animatable.

Note: Compare this to a property like display: adding it to a transition list has no visible easing effect, since block and none have no in-between state for the browser to interpolate.
