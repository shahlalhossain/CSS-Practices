CSS Grid Container

This lesson covers every property that goes on the grid container itself: sizing the columns and rows with grid-template-columns/grid-template-rows, spacing items apart with gap, aligning the whole grid (or its items as a group) with justify-content/align-content/justify-items/align-items, and laying out named regions with grid-template-areas. The next lesson, CSS Grid Item, covers properties that target one grid item individually.

grid-template-columns

The grid-template-columns property defines both how many columns a grid has and how wide each one is: one value is listed per column. Each example below lays out 6 items across 3 columns, which wrap onto a second row.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto;
         }
     </style>
</head>
<body>

     <h1>grid-template-columns: auto auto auto</h1>
     <p>Three equal-ish columns, each sized to fit its content:</p>

     <div class="container">
         <div>1</div><div>2</div><div>3</div>
         <div>4</div><div>5</div><div>6</div>
     </div>

</body>
</html>

grid-template-rows

grid-template-rows works exactly like grid-template-columns, but for row heights instead of column widths — one value per explicit row. Rows beyond however many are listed fall back to an automatic height.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-rows: 80px 200px;
         }
     </style>
</head>
<body>

     <h1>grid-template-rows: 80px 200px</h1>
     <p>With no grid-template-columns set, each of the 8 items becomes its own column; the first row is 80px tall, the second is 200px:</p>

         <div>5</div><div>6</div><div>7</div><div>8</div>

justify-items and align-items

Where justify-content/align-content position the grid as a whole, justify-items and align-items position each item inside its own cell — useful when an item is narrower or shorter than the cell it occupies. Both default to stretch, which is why items normally fill their cell completely; the example below sets each item to a fixed width/height smaller than its cell so the effect is visible.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto;
             grid-template-rows: 100px 100px;
             justify-items: center;
         }
         .container div { width: 80px; }
     </style>
</head>
<body>

         <div>1</div><div>2</div><div>3</div>
         <div>4</div><div>5</div><div>6</div>
     </div>

</body>
</html>

grid-template-areas

grid-template-areas lays out a grid by naming regions instead of counting rows and columns. Each string in the value is one row, and each word in the string is the name of the area that cell belongs to — repeating a name merges adjacent cells into one larger area. Individual items are then assigned to a named area with the grid-area property, which must match one of the names used in grid-template-areas.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             gap: 10px;
             grid-template-columns: 1fr 2fr 1fr;
             grid-template-areas:
                 "header header header"
                 "nav main aside"
                 "footer footer footer";
         }
         .header { grid-area: header; }
         .nav { grid-area: nav; }
         .main { grid-area: main; }
         .aside { grid-area: aside; }
         .footer { grid-area: footer; }
     </style>
</head>
<body>

     <div class="container">
         <div class="header">Header</div>
         <div class="nav">Nav</div>
         <div class="main">Main</div>
         <div class="aside">Aside</div>
         <div class="footer">Footer</div>
     </div>

</body>
</html>

A classic page skeleton: a full-width header, a nav/main/aside row, and a full-width footer, named rather than counted:

Header
Nav
Main
Aside
Footer

Note: This example is a reconstruction of W3Schools' standard header/nav/main/aside/footer teaching pattern for grid-template-areas, since its exact source markup wasn't recoverable; the property values and behavior shown are accurate to the spec. A cell can be left empty in the layout by using a period (.) instead of a name.

CSS Grid Container Properties

Property Description
displaySpecifies the type of box used for a grid container
grid-template-columnsSpecifies the number and widths of columns
grid-template-rowsSpecifies the number and heights of rows
grid-template-areasSpecifies named grid areas
grid-templateShorthand for grid-template-rows, grid-template-columns, and grid-template-areas
column-gapSpecifies the gap between the columns
row-gapSpecifies the gap between the rows
gapShorthand for row-gap and column-gap
justify-contentAligns the whole grid within the container (row axis)
align-contentAligns the whole grid within the container (column axis)
place-contentShorthand for align-content and justify-content
justify-itemsAligns grid items inside their cell (row axis)
align-itemsAligns grid items inside their cell (column axis)
grid-auto-columnsSpecifies a default size for implicitly created columns
grid-auto-rowsSpecifies a default size for implicitly created rows
grid-auto-flowSpecifies how auto-placed items are inserted into the grid
gridShorthand for all of the above grid-template-* and grid-auto-* properties
