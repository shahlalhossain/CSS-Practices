CSS Grid Items

This lesson covers the properties that target an individual grid item rather than the container: placing an item across specific grid lines with grid-column-start/grid-column-end/grid-row-start/grid-row-end (and their shorthands), naming an item with grid-area, reordering items with order, and aligning a single item within its cell with justify-self/align-self.

Grid Lines

Every grid has numbered grid lines running between its columns and rows, starting at 1. A 5-column grid has 6 vertical lines (1 through 6); a grid item can be stretched across more than one cell by telling it which line to start and end on.

grid-column-start and grid-column-end

grid-column-start and grid-column-end specify which vertical grid lines an item spans between. The container below has 5 columns; item "1" is set to start at line 1 and end at line 3, so it spans the first two columns.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto auto auto;
         }
         .item1 {
             grid-column-start: 1;
             grid-column-end: 3;
         }
     </style>
</head>
<body>

     <h1>grid-column-start / grid-column-end</h1>

     <div class="container">
         <div class="item1">1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
         <div>5</div>
     </div>

</body>
</html>

Item "1" spans from line 1 to line 3 (two columns):

Note: Spans are inclusive of the start line and exclusive of the end line — 1 to 3 covers the space between lines 1 and 3, which is two column tracks, not three.

The grid-column Shorthand and span

grid-column is a shorthand for grid-column-start / grid-column-end. Instead of naming an explicit end line, the span keyword says how many columns to cover starting from the start line — often more convenient than calculating the exact end line yourself.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto auto auto;
         }
         .item1 {
             grid-column: 1 / span 3;
         }
     </style>
</head>
<body>

     <h1>grid-column: 1 / span 3</h1>

     <div class="container">
         <div class="item1">1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
         <div>5</div>
     </div>

</body>
</html>

Item "1" starts at line 1 and spans 3 columns:

grid-row-start / grid-row-end and the grid-row Shorthand

grid-row-start/grid-row-end (and their grid-row shorthand) work exactly the same way as the column properties above, but span horizontal grid lines instead of vertical ones. Each example below gives the container explicit row heights so the span is visible.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto auto auto;
             grid-template-rows: 80px 80px 80px;
         }
         .item1 {
             grid-row-start: 1;
             grid-row-end: 3;
         }
     </style>
</head>
<body>

     <h1>grid-row-start / grid-row-end</h1>

     <div class="container">
         <div class="item1">1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
         <div>5</div>
     </div>

</body>
</html>

Item "1" spans from row line 1 to row line 3 (two rows tall):

Combining Column and Row Spans

grid-column and grid-row can be set together on the same item, making it span a rectangular block of cells rather than just one row or one column.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto auto auto;
             grid-template-rows: 80px 80px;
         }
         .item1 {
             grid-column: 1 / span 2;
             grid-row: 1 / span 2;
         }
     </style>
</head>
<body>

     <h1>grid-column + grid-row combined</h1>

     <div class="container">
         <div class="item1">1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
         <div>5</div>
         <div>6</div>
     </div>

</body>
</html>

Item "1" spans 2 columns and 2 rows — a 2×2 block:

Naming Grid Items with grid-area

Besides working as a shorthand for the four start/end line properties, grid-area can give an item a name, which is then referenced from the container's grid-template-areas (covered in the previous lesson). Naming items this way often reads more clearly than tracking line numbers, especially for a whole-page layout.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             gap: 10px;
             grid-template-columns: repeat(6, 1fr);
             grid-template-areas:
                 "header header header header header header"
                 "menu main main main main right"
                 "menu footer footer footer footer footer";
         }
         .item1 { grid-area: header; }
         .item2 { grid-area: menu; }
         .item3 { grid-area: main; }
         .item4 { grid-area: right; }
         .item5 { grid-area: footer; }
     </style>
</head>
<body>

     <div class="container">
         <div class="item1">Header</div>
         <div class="item2">Menu</div>
         <div class="item3">Main</div>
         <div class="item4">Right</div>
         <div class="item5">Footer</div>
     </div>

</body>
</html>

A page skeleton where a tall menu area spans two rows beside a stacked main/footer column:

The order Property

Exactly like the flexbox order property covered earlier in this course, order on a grid item changes its visual position without touching the HTML source order. Items render from lowest order value to highest.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto;
         }
         .item1 { order: 3; }
         .item2 { order: 6; }
         .item3 { order: 1; }
         .item4 { order: 2; }
         .item5 { order: 4; }
         .item6 { order: 5; }
     </style>
</head>
<body>

     <h1>The order Property</h1>

     <div class="container">
         <div class="item1">1</div>
         <div class="item2">2</div>
         <div class="item3">3</div>
         <div class="item4">4</div>
         <div class="item5">5</div>
         <div class="item6">6</div>
     </div>

</body>
</html>

Items 1–6 are given orders 3, 6, 1, 2, 4, 5 — they render sorted as 3, 4, 1, 5, 6, 2:

justify-self and align-self

justify-self and align-self are the single-item counterparts of the container's justify-items/align-items (covered in the previous lesson) — they override the container's setting for just one item, positioning it within its own cell instead of the whole grid following the same rule.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         .container {
             display: grid;
             grid-template-columns: auto auto auto auto auto auto;
         }
         .item1 { justify-self: right; }
         .item6 { justify-self: center; }
     </style>
</head>
<body>

     <h1>justify-self</h1>

     <div class="container">
         <div class="item1">1</div>
         <div>2</div>
         <div>3</div>
         <div>4</div>
         <div>5</div>
         <div class="item6">6</div>
     </div>

</body>
</html>

Item "1" is pushed to the right of its cell; item "6" is centered in its cell; the rest keep the default stretch:

CSS Grid Item Properties

Property Description
grid-column-startSpecifies where to start a grid item on the row axis
grid-column-endSpecifies where to stop a grid item on the row axis
grid-columnShorthand for grid-column-start / grid-column-end
grid-row-startSpecifies where to start a grid item on the column axis
grid-row-endSpecifies where to stop a grid item on the column axis
grid-rowShorthand for grid-row-start / grid-row-end
grid-areaShorthand for grid-row-start / grid-column-start / grid-row-end / grid-column-end, or assigns a name for use with grid-template-areas
orderSets the order of a grid item relative to its siblings
justify-selfAligns a single grid item along the row axis, inside its cell
align-selfAligns a single grid item along the column axis, inside its cell
