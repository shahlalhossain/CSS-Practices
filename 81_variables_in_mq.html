CSS Variables in Media Queries

A variable declared inside a selector isn't fixed for the whole page — it can be redeclared inside a @media block for the same selector, and every rule reading that variable with var() picks up the new value automatically once the breakpoint is crossed. This gives a second, often simpler way to build responsive styling, as an alternative to writing out separate property values per breakpoint.

Below, --mq-fontsize starts at 20px on the .mq-var-demo-1 box. A media query says: once the viewport is 450px or wider, override that same variable to 40px. Resize the browser (or this preview pane) across 450px to see the font size jump.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <style>
         :root {
             --primary-bg-color: #1e90ff;
             --primary-color: #ffffff;
         }
         body {
             background-color: var(--primary-bg-color);
         }
         .container {
             --fontsize: 20px;
             color: var(--primary-bg-color);
             background-color: var(--primary-color);
             padding: 15px;
             font-size: var(--fontsize);
         }
         .container h2 {
             border-bottom: 2px solid var(--primary-bg-color);
         }

         @media screen and (min-width: 450px) {
             .container {
                 --fontsize: 40px;
             }
         }
     </style>
</head>
<body>

     <div class="container">
         <h2>Lorem Ipsum</h2>
         <p>When the browser's width is less than 450px, the font-size of this div is 20px. When it is 450px or wider, the --fontsize variable becomes 40px. Resize the browser window to see the effect.</p>
     </div>

</body>
</html>

A @media block isn't limited to overriding a single variable — any number of variables, including ones declared at the root level, can be reassigned together inside the same breakpoint. Here, crossing 450px changes both the font-size variable and the background/text color variable in one go:

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <style>
         :root {
             --primary-bg-color: #1e90ff;
             --primary-color: #ffffff;
         }
         body {
             background-color: var(--primary-bg-color);
         }
         .container {
             --fontsize: 20px;
             color: var(--primary-bg-color);
             background-color: var(--primary-color);
             padding: 15px;
             font-size: var(--fontsize);
         }
         .container h2 {
             border-bottom: 2px solid var(--primary-bg-color);
         }

         @media screen and (min-width: 450px) {
             .container {
                 --fontsize: 40px;
             }
             :root {
                 --primary-bg-color: lightblue;
             }
         }
     </style>
</head>
<body>

     <div class="container">
         <h2>Lorem Ipsum</h2>
         <p>When the browser's width is 450px or wider, set the --fontsize variable to 40px and the --primary-bg-color variable to lightblue. Resize the browser window to see the effect.</p>
     </div>

</body>
</html>

Lorem Ipsum

When this preview pane is 450px or wider, --mq-fontsize2 becomes 40px and --mq-bg2 becomes lightblue. Resize the browser window to see the effect.
