CSS Units

Many CSS properties take a "length" value — font-size, width, margin, padding, border, and more all need a unit attached to a number before the browser can size them. CSS units fall into two groups:

  • Absolute units — fixed, screen-size independent
  • Relative units — sized relative to another length, such as a parent element, the root element, or the viewport

CSS Absolute Units

Absolute units are fixed — a length expressed in any of them renders at exactly that physical size no matter the screen. Because they don't adapt when the screen size changes, they're generally discouraged for everyday web layout, but they do make sense when the output medium is known in advance, such as a print stylesheet. px (pixels) is by far the most commonly used absolute unit on the web.

Unit Description Example
cmCentimeters2cm
mmMillimeters20mm
inInches (1in = 96px = 2.54cm)1in
pxPixels (1px = 1/96th of 1in). The most used absolute unit; a reliable reference for screen displays.16px
ptPoints (1pt = 1/72 of 1in)12pt
pcPicas (1pc = 12pt)3pc

Setting font sizes with px gives full, precise control over text size, but a pixel value does not scale with the user's screen — and browsers that let a reader change their default font size (not just zoom) won't affect px-based text the way they will relative units.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         h1 { font-size: 40px; }
         h2 { font-size: 30px; }
         p { font-size: 17px; }
     </style>
</head>
<body>

     <h1>This is heading 1</h1>
     <h2>This is heading 2</h2>
     <p>This is a paragraph, set with a fixed pixel size.</p>

</body>
</html>

This is heading 1

This is heading 2

This is a paragraph, set with a fixed pixel size.

Note: No whitespace is allowed between the number and the unit (20 px is invalid, 20px is correct) — except for a value of zero, which never needs a unit at all (margin: 0;).

CSS Relative Units

Relative units size an element in relation to something else — a parent's font size, the root element's font size, or the viewport — rather than to a fixed physical measurement. Because of that, they scale naturally across different screen sizes and are the better default for responsive design. The two most used relative units are em and rem.

Unit Description
emRelative to the font-size of the element's parent (2em means 2 times the size of the parent's font)
remRelative to the font-size of the root (<html>) element, regardless of nesting depth
%Relative to the parent element's corresponding value
vw1% of the viewport's width
vh1% of the viewport's height
vmin1% of the viewport's smaller dimension (width or height)
vmax1% of the viewport's larger dimension (width or height)
chRelative to the width of the "0" (zero) character of the element's font

With a parent font size of 16px, 2.5em computes to 40px. Unlike pixels, text sized with em still responds if the reader changes their browser's default font size.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         body { font-size: 16px; }
         h1 { font-size: 2.5em; } /* 40px */
         h2 { font-size: 1.875em; } /* 30px */
         p { font-size: 1em; } /* 16px */
     </style>
</head>
<body>

     <h1>This is heading 1</h1>
     <h2>This is heading 2</h2>
     <p>This is a paragraph, sized in em units.</p>

</body>
</html>

This is heading 1

This is heading 2

This is a paragraph, sized in em units.

rem works the same way as em, but always measures against the root <html> element's font size instead of the immediate parent — so nested elements don't compound unexpectedly, and changing one root value rescales the whole page at once.

Example Code Sample Output
<!DOCTYPE html>
<html>
<head>
     <style>
         html { font-size: 16px; }
         h1 { font-size: 2.5rem; } /* 40px */
         h2 { font-size: 1.875rem; } /* 30px */
         p { font-size: 1rem; } /* 16px */
     </style>
</head>
<body>

     <h1>This is heading 1</h1>
     <h2>This is heading 2</h2>
     <p>This is a paragraph, sized in rem units.</p>

</body>
</html>

This is heading 1

This is heading 2

This is a paragraph, sized in rem units.

Tip: The em and rem units are perfect for creating scalable and responsive websites.
